# Risk Levels

Risk levels describe how risky an action is for the Personal AI Agent.

## LOW

An action with low potential risk.

Examples:
- Reading public information
- Performing a local calculation
- Processing non-sensitive data locally

## MEDIUM

An action that requires more caution.

Examples:
- Accessing private personal information
- Modifying user data
- Performing an action with moderate consequences

## HIGH

An action that could cause significant privacy or security problems.

Examples:
- Sending sensitive information externally
- Uploading local-only data
- Using credentials or authentication information
- Performing high-impact external actions

## Important Rule

Risk level describes the risk of an action.

It is not the same as data classification.

Data classification asks:

"What kind of data is this?"

Risk level asks:

"How risky is this action?"

Permission state asks:

"What should the system do?"

The future security policy will use these concepts together.
